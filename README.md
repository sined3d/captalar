# CaptaLar — primeira versão PWA

Esta é uma primeira versão funcional do CaptaLar para validar o fluxo no celular.

## Já funciona
- Cadastro de imóvel
- GPS do navegador e preenchimento de endereço quando o serviço de geocodificação responde
- Fotos pela câmera/galeria
- Marca d'água CAPTALAR + ID
- Cadastro do proprietário
- Assinatura na tela
- Tela de conferência
- Salvamento local no navegador
- Lista de imóveis
- Painel com contadores
- Instalação como PWA quando hospedado em HTTPS

## Importante
Esta versão é um protótipo funcional local. Os dados ficam no navegador do aparelho. Ainda NÃO há banco de dados online, login real, sincronização entre captadores/imobiliárias ou assinatura com validade jurídica.

## Próxima fase
Conectar um backend/banco de dados, autenticação e painel multi-imobiliária. Depois publicar em HTTPS para uso real.
